# Персональный сайт-портфолио художника-постановщика

## Что это
Персональный сайт театрального художника-постановщика с портфолио работ, биографией и формой для связи. Заменяет PDF-файлы единой онлайн-точкой входа.

## Позиционирование
Сайт должен показывать автора визуальных миров, который соединяет:
- театральный опыт и сценографическое мышление
- сторителлинг и работу с образами
- AI-иллюстрации и в будущем AI-видео

Ключевое сообщение главной страницы: **художник с театральным мышлением, который создаёт сценографию, визуальные концепции, AI-иллюстрации и AI-видео для театра, брендов, артистов и событий.**

Сильная сторона: театральный бэкграунд делает AI-контент не просто красивыми картинками, а визуальными историями — атмосферами, сценами, мирами, драматургией бренда.

## Для кого
- Режиссёры и театры — ищут художника для постановки
- Продюсеры и менеджеры концертной индустрии — ищут художника для ивентов, выступлений артистов, концертов
- Ивент-агентства и бренды — ищут художника для мероприятий и коллабораций
- Частные заказчики — ищут художника для проекта
- SMM-менеджеры и креативные продюсеры — ищут визуальный контент, образы, атмосферу для брендов и проектов
- Артисты и музыкальные проекты — ищут визуальный стиль, афиши, сторителлинг
- Европейские компании и бренды — ищут необычный визуальный контент и концепции

## Проблема
Портфолио существует только в виде PDF-файлов — неудобно делиться, сложно воспринимать, нет контекста о процессе и личности автора. Потенциальные работодатели и заказчики не могут быстро понять стиль работы, опыт и способ мышления художника, а также не имеют простого способа выйти на связь.

## Основные функции
- Галерея работ с полноэкранным просмотром фотографий
- Переключение языка сайта: русский / английский
- Скачать CV одной кнопкой (PDF)
- Контакт: email + мессенджер (Telegram или WhatsApp)
- Адаптивная вёрстка: десктоп и мобильная версия
- Тёмная тема оформления

## Страницы / экраны
1. **Главная** — первое впечатление: кто это, что делает, ключевые работы. Должна сразу считываться как: театральный художник + визуальные миры + AI-контент. *(Нужно отдельно продумать)*
2. **Сценография** — галерея спектаклей, концертов, ивентов и коллабораций с брендами; карточки проектов с фотографиями
3. **Как я работаю** — подход, этапы, эскизы, макеты, референсы; показывает мышление, а не только результат
4. **Резюме** — список театров, постановок, наград
5. **Обо мне** — биография, профессиональный путь, философия работы; упомянуть мастер-классы и обучение как часть профессионального профиля
6. **Контакт** — email и мессенджер для запроса сотрудничества
7. **AI Visuals** *(будущий раздел, coming soon)* — AI-иллюстрации и AI-видео: визуальные концепты для брендов, образы для соцсетей, moodboard-материалы, кампейны, афиши, визуальные истории для артистов, сценографические и event-концепции. Появится, когда будут готовы примеры работ.
8. **Training / Workshops** *(будущий раздел, coming soon)* — мастер-классы, интенсивы, образовательные программы, тренинги для компаний и креативных команд. Появится, когда будет готов материал с фото и описанием программ.

### Принципы дизайна
- Минимализм, но не стерильность — сценография требует визуальной силы
- Самобытность: не копировать шрифты или приёмы референсов
- Тёмная тема как основа
- Фотографии — главный визуальный элемент, всё остальное им не мешает

## Технические заметки
- Двуязычность (RU / EN): переключатель языка, весь контент готовится в двух версиях
- Много фотографий: нужна оптимизация изображений для быстрой загрузки
- Полноэкранный просмотр: лайтбокс с листанием стрелками
- Тёмная тема: основная, светлую не планируем
- CV: PDF-файл обновляется вручную при изменениях
- Если фотографий по процессу мало — можно встроить их внутрь карточек проектов в Сценографии, без отдельной страницы
